# perepiska-v-bazu

Плагин для Claude Code. Из переписки с клиентами он делает разбор частых вопросов и ответов. Вы правите разбор руками, и из него собирается документ для базы знаний бота или ИИ-продавца.

Подходит для выгрузок из Telegram, WhatsApp и CSV-файлов из CRM. Обычно базу знаний пишут по памяти, и половины настоящих вопросов в ней нет. Здесь она собирается из того, что клиенты действительно спрашивали и что вы им действительно отвечали.

## Как это работает

1. **Разбор.** Вы даёте выгрузку переписки. Скрипт на вашем компьютере убирает стикеры и служебные сообщения и скрывает телефоны, почты, ники и имена участников. Потом Claude пишет файл `razbor.md`:
   - темы по частоте;
   - как спрашивают клиенты;
   - все ваши ответы с датами;
   - пометки «ответа нет» и «ответы расходятся».
2. **Правка.** Вы открываете `razbor.md`, отмечаете темы, которые берёте в базу, и правите ответы.
3. **Сборка.** Из исправленного разбора собирается `baza-znaniy.md`: только отмеченные темы и только ваши ответы. Если где-то нет ответа, осталось расхождение или личные данные, сборка останавливается и говорит, что поправить.

## Что нужно заранее

- **Claude Code 2.1.292 или новее.** Проверить версию в терминале:

  ```bash
  claude --version
  ```

- **Python 3.9 или новее.** На Mac он обычно уже есть. Проверка:

  ```bash
  python3 --version
  ```

  Если Mac предложит установить инструменты разработчика, согласитесь и повторите команду.

## Установка

В окне Claude Code одной командой:

```
/plugin install perepiska-v-bazu --marketplace aitaxpox/perepiska-v-bazu
```

Или в терминале двумя командами:

```bash
claude plugin marketplace add aitaxpox/perepiska-v-bazu
```

```bash
claude plugin install perepiska-v-bazu@perepiska-v-bazu
```

### Проверка, что поставилось

Откройте новое окно Claude Code и наберите `/perepiska`. В подсказке должны появиться `/perepiska-v-bazu:razbor-perepiski` и `/perepiska-v-bazu:sborka-bazy`.

### Установка в Codex

В терминале двумя командами:

```bash
codex plugin marketplace add aitaxpox/perepiska-v-bazu
```

```bash
codex plugin add perepiska-v-bazu@perepiska-v-bazu
```

Потом откройте новый чат Codex в папке с выгрузкой и напишите, как в примере ниже: «разбери переписку из telegram-result.json».

## Пример за пять минут, на учебной переписке

Все люди и данные в учебной переписке выдуманы.

1. Создайте пустую папку и скачайте в неё учебную выгрузку:

   ```bash
   mkdir -p ~/Desktop/proba-razbora && cd ~/Desktop/proba-razbora
   ```

   ```bash
   curl -LO https://raw.githubusercontent.com/aitaxpox/perepiska-v-bazu/main/examples/telegram-result.json
   ```

2. Откройте Claude Code в этой папке и напишите:

   > разбери переписку из telegram-result.json

3. Claude спросит, кто из участников вы. Ответьте: «Студия Учебная».
4. В папке появится `razbor.md` с двумя темами: цена абонемента и оплата частями.
5. Откройте `razbor.md`. У обеих тем замените `- [ ] в базу` на `- [x] в базу`. В теме «Оплата частями» уберите метки в квадратных скобках: `[почта]`, `[ник]`, `[телефон]`. Это скрытые данные клиента. В ответе впишите вместо них свой контакт, а из вопроса клиента метку просто удалите.
6. Напишите Claude:

   > собери базу знаний из razbor.md

   Получится `baza-znaniy.md`:

   ```markdown
   ## Оплата частями

   Как спрашивают: «А можно оплатить частями?»

   Да, можно в два платежа.
   ```

Если на шаге 6 вы забудете убрать какую-то метку, сборка остановится и подскажет, что поправить. Так и задумано.

## Как выгрузить свою переписку

| Откуда | Как выгрузить | Что дать Claude |
|---|---|---|
| Telegram для Mac | Откройте чат и выберите в его меню «Экспорт истории чата». Медиафайлы можно не включать: они не читаются | папку `ChatExport_…` целиком (внутри `messages.html`) |
| Telegram Desktop (Windows, Mac, Linux) | Меню чата (⋮) → «Экспорт истории чата», формат HTML или JSON, без медиа | папку `ChatExport_…` или файл `result.json` |
| WhatsApp | В чате: «Экспорт чата» → «Без медиафайлов» | файл `.txt` (из архива .zip его нужно достать) |
| CRM | Выгрузка переписки в CSV, где одна строка — одно сообщение. Excel сохраните как CSV | файл `.csv`. Claude покажет колонки и спросит, где автор, дата и текст |

В большом чате (больше 3000 сообщений) Claude спросит, с какой даты брать переписку. Обычно хватает последнего года.

## Границы

- **Голосовые, фото, видео и стикеры не читаются.** Скрипт только считает их: например, «пропущено голосовых: 17».
- **Пересланные сообщения не берутся**, они тоже только считаются.
- **Имя постороннего человека внутри текста может проскочить.** Скрывается имя, телефон или ник любого участника чата. Но если клиент пишет «передайте Маше», а Маши в чате нет, скрипт не поймёт, что это имя. Просмотрите разбор глазами.
- **Ответы не придумываются.** Если вы клиенту не отвечали, в разборе будет «ответа нет», и ответ впишете вы.
- **CSV:** одна строка — одно сообщение. Если CRM складывает весь диалог в одну ячейку, плагин его не разберёт.
- **ВК и Битрикс24 напрямую не подключаются**, нужен файл выгрузки.
- **Текст переписки читает Claude**, то есть он уходит в Anthropic. Скрипт заранее скрывает в тексте телефоны, почты, ники и имена участников, но всё остальное Claude видит. Ещё на первом шаге Claude видит список участников чата с именами: так вы выбираете, кто из них вы. Для CSV он видит и первые строки файла с уже скрытыми телефонами и почтами. В Codex переписку так же читает модель OpenAI. Решите сами, можно ли так поступить с вашей перепиской.

## На чём проверено

- Claude Code 2.1.318 на macOS, Python 3.9 и 3.13.
- Выгрузки: Telegram для Mac (HTML), Telegram Desktop (JSON), WhatsApp с iPhone и Android, CSV в кодировках UTF-8 и Windows-1251.
- Codex (codex-cli 0.166) на macOS: установка с GitHub и весь пример, от разбора до базы знаний.
- **Не проверено:** Windows.
