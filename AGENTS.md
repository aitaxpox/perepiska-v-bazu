# perepiska-v-bazu

Открытый плагин для Claude Code: переписка с клиентами (Telegram, WhatsApp, CSV) → разбор `razbor.md`, который человек правит руками → документ базы знаний.

## Как устроено

- `skills/razbor-perepiski/` — первый заход: скилл и скрипт `scripts/razobrat.py`.
- `skills/sborka-bazy/` — второй заход: скилл и скрипт проверки перед сборкой.
- `examples/` — учебные переписки, все люди и данные выдуманы.
- `tests/` — тесты на `unittest`.

## Правила

- Скрипты только на стандартной библиотеке Python и совместимы с Python 3.9: на Mac у человека может быть только системный `python3`.
- Тест пишется раньше кода. Проверка: `python3 -m unittest discover -s tests -v`, на 3.9 и на 3.13.
- Агент не придумывает ответы: в разбор и в базу идёт только то, что есть в переписке или в правке человека.
- Телефоны, почты, ники и имена участников в тексте скрываются скриптом до того, как текст видит агент. Исключение — шаг `--info`: он показывает список участников с именами, чтобы человек выбрал, кто из них он.
- В репозиторий не попадают настоящие переписки (папка `private/` в `.gitignore`), `.env` и ключи. `.env` не читать.
- Тексты для людей — по-русски, простыми словами.
