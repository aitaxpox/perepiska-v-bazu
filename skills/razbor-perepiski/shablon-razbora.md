# Разбор переписки: ‹название бизнеса или чата›

Источник: ‹файл выгрузки›, ‹формат›. Период: ‹с — по›. Сообщений с текстом: ‹N›, клиентов: ‹N›.
Скрыто скриптом: ‹что и сколько›. Пропущено без текста: ‹голосовые, фото и т. п.›.

## Как работать с этим файлом

1. Прочитайте темы. Ответы из переписки приведены дословно, с датами.
2. В каждой теме, которую берёте в базу, поставьте `x` в строке `- [ ] в базу`, чтобы получилось `- [x] в базу`.
3. Из отмеченной темы в базу идут только два блока: «Как спрашивают» и «Ответ для базы». Остальные блоки — справка для вас, их не трогайте.
4. В квадратных скобках — скрытые данные: `[имя]`, `[телефон]`, `[почта]`, `[ник]`. В этих двух блоках их быть не должно. Из вопроса клиента удалите их вместе со словами вокруг. В ответе впишите вместо них свой контакт или удалите. В «Ответе для базы» поправьте или впишите ответ, метки вида ‹…› замените своим текстом.
5. Строки с ⚠️ в «Пометках» удалите, когда решили, что с ними делать. Строки с ℹ️ можно оставить.
6. Скажите агенту: «собери базу знаний из razbor.md».
