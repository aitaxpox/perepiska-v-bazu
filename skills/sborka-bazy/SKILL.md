# Сборка базы знаний из разбора

`razbor.md` сделал скилл разбора переписки, а человек его исправил: отметил темы «в базу» и вписал ответы. Сборку делает скрипт `sobrat.py`. Он берёт только отмеченные темы и только «Ответ для базы», ничего не дописывает и останавливается, если что-то не готово.

## Главные правила

- **Не исправляй `razbor.md` сам** и не ставь галочки «в базу». Правки разрешены, только если человек прямо попросил конкретную: «в теме Цена впиши ответ: …».
- **Не придумывай ответы**, даже когда скрипт пишет «нет ответа». Скажи человеку, какой темы касается, и спроси.
- `--kontakty-ok` добавляй, только если человек подтвердил, что телефон или почта в ответе — контакт его компании, а не клиента.
- Готовый документ не переписывай и не улучшай: в базе должно быть ровно то, что утвердил человек.
- Файл `.env` не открывай.

## Шаги

1. **Найди разбор.** Путь в `$ARGUMENTS` или в сообщении человека. Иначе возьми `razbor.md` в текущей папке, а если его нет — спроси.

2. **Спроси, как собрать.**
   - Один файл `baza-znaniy.md` (так по умолчанию) — удобно читать и загрузить целиком.
   - Папка, по файлу на тему — удобнее для бота, который ищет ответ по кускам базы.

3. **Запусти сборку.**

   Один файл:

   ```bash
   python3 ${CLAUDE_SKILL_DIR}/scripts/sobrat.py "ПУТЬ/razbor.md" -o baza-znaniy.md
   ```

   Папка по темам:

   ```bash
   python3 ${CLAUDE_SKILL_DIR}/scripts/sobrat.py "ПУТЬ/razbor.md" --papka baza-znaniy
   ```

4. **Сборка остановилась** (скрипт напечатал «Сборка остановлена»): покажи список проблем как есть и коротко объясни, что сделать в `razbor.md`:
   - «нет ответа» — вписать ответ в «Ответ для базы» или снять отметку «в базу»;
   - «не решена пометка ⚠️» — решить и удалить строку с ⚠️;
   - «осталась метка [почта]» и подобные — вписать настоящий контакт компании или убрать метку;
   - «в ответе есть телефон» — спросить, контакт ли это компании. Если да — собрать заново с `--kontakty-ok`.

   Когда человек исправил, запусти сборку ещё раз.

5. **Сборка прошла:** скажи, сколько тем вошло и где лежит результат. Перескажи напоминания из пометок ℹ️, если скрипт их напечатал. Предложи открыть документ и проверить его глазами перед загрузкой в бота.
